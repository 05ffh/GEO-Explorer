# 复测收敛设计（remeasure.py + converge.py）

> 状态：**设计已定稿**（2026-09-15）。四项细节已与用户对齐，已记 spec，可进入 build。
> 对应 spec：P0-E 复测收敛 / ⑪「复测收敛循环」。用户明确 **B 模式**：每轮采满 35 题 + 归因重判。

## 0. 要解决的问题

单次测量/判定是**噪声样本，不是真值**。已实测三类噪声：

| 噪声源 | 证据 | 收敛机制 |
|---|---|---|
| AI 回答随机 | 豆包命中率 16→52→16% | L1 同天 K 次采样 → 区间 |
| 判定随机 | 同样 40 题两轮判出 31↔48 条"有未引用" | L2 跨 run 独立判定累积 |
| 时间漂移 | V3.2→V4 隔 6 天命中率 16→52 | L3 跨 run 漂移检测 |

收敛目标 = 回答三个可决策问题：
1. **命中率到底是多少？**（能否当合同基线）
2. **"甲方有但 AI 未引"是稳定劣势还是随机噪声？**（铺内容方向是否成立）
3. **哪个数字已足够可信、可以行动？**

## 1. 设计原则（第一性原理）

1. **采样噪声 vs 漂移必须先分开**，否则"平均"就是错的：同时刻 K 次可平均；隔天不可平均，只能检测。
2. **命中率是标量 → 可平均出区间**（k/R → 概率 → 均值±CI）。
3. **劣势维度是语义标签 → 只能跨 run 计出现率**，不能做 0/1 平滑。判定方差靠"每次 run 是一次独立判定抽样"来平。
4. **收敛不是无限采样**：不动点（连续两次结论不变）+ 区间达标 + 硬上限（R_max），三者取先到者。
5. **确定性归系统，语义归子 agent，仲裁归主 agent**——判定质量闸保证额度买的 AI 回答不被判定层污染。

## 2. 架构与复用（不造轮子）

| 地基 | 作用 |
|---|---|
| 问法指纹 `question_fingerprint` | 同基线 3 轮 → 同 run 快照累积，**不新开基线** |
| `measurement_snapshots`（judge/rejudge） | n 次采样 = n 个 sealed 版本，天然支撑取均值/区间 |
| `compare_measure.py` | 跨版本对比（跨轮差异） |
| `finalize_v4.py seal` | 每轮收口，版本留痕 |
| `_ATTRIBUTION_SPEC` + G1-G5 判定质量闸 | 归因判定协议（已冻结） |

## 3. remeasure.py（采集编排）

### 3.1 调度（用户已定）
```
t=0       轮 1 采集（35 题）+ 归因判定 + seal
t-30min   通知"轮 2 将于 2 小时后采（待采）"
t=2h      轮 2 采集 + 归因判定 + seal
t-30min   通知"轮 3 将于 2 小时后采（待采）"
t=4h      轮 3 采集 + 归因判定 + seal   ← R_max=3
```
- 间隔 2h、跨度 4h（仍远小于漂移窗口）。
- 调度员 = 主 agent（我），用 **Claude Code 定时任务（CronCreate）** 编排：每轮 t-30min 触发"待采"通知、t 触发采集。用户可围观/确认。
- 每轮 = 复用 `run_measure`（同基线、同指纹）+ 归因判定 + `finalize_v4 seal` → 新增一个 rejudge 快照。

### 3.2 判定质量闸（G1-G5，主 agent 每轮执行）
- **G1** schema 校验：非法 dim/type/pick/evidence → 打回该平台重判。
- **G2** 抽查重审：主 agent 按语料复核 6-8 题高风险判定（设施/位置 type 边界、价格/品牌必须 true）；发现系统性漂移 → **先修规范再重判**，不带病聚合。
- **G3** 跨轮翻转仲裁：同一 (题×维度) 在 run1/run2 type 翻转 → 主 agent 查语料裁决并钉死。
- **G4** 判定方差门：平台跨轮翻转率 > 20% → 判定协议不可信，先修再继续。
- **G5** 存疑键终裁：3 轮后"模糊"key，若落地方向依赖 → 主 agent 终裁或加一轮确认。
- 确定性后处理（每轮）：dim 归一化、价格/品牌强制 true_disadvantage、evidence 剥离语料注释。

### 3.3 哨兵
- 某题 3 轮**逐字相同** → 标"疑缓存/低噪声"，不武断归因，交给 converge 复核。

### 3.4 成本表（B 模式，R_max=3）
| 项 | 单次 | B 模式 3 轮（分层） |
|---|---|---|
| 提问 | 140 | ≈320（波动平台命中 + 全平台归因 3 轮；稳定平台命中 1 轮） |
| 归因判定（子 agent） | 4 平台 | 12 次平台·轮 |
| 主 agent 介入 | — | G1-G5 × 3 轮 |

## 4. converge.py（聚合与收敛判定）

输入：同基线 run 的快照列表（3 个）。

### 4.1 L1 命中率（标量 + 区间）
- 每题：k/R 次命中 → 推荐概率 p̂_q。
- 平台命中率 p̂ = mean(p̂_q)；区间 = 二项近似 1.96·√(p̂(1−p̂)/N)，N = 题数×R。
- 输出：每平台 **均值 ± 区间** + 每题概率表 + 有效题数。
- 例：豆包 25 题 × 3 轮 = 75 样本，p̂=16% → 半宽 ≈ ±8.3pp。

### 4.2 L2 劣势维度（语义标签 + 出现率）
- 键 = (题 × 维度 × type)。每 run 一次出现判定。
- 出现率 = 出现次数 / 总判定次数。**聚合口径（已对齐）：四平台合并计出现率**（跨平台×轮），
  并**标注平台分布**（该维度出现在哪几个平台）暴露平台特异性；结论给甲方整体，不分平台割裂。
- 分档：
  - ≥ 2/3·R → **稳定出现**（决策：采信）
  - ≤ 1/3·R → **稳定未现**（决策：不采信）
  - 中间 → **模糊**（待更多样本 / G5 终裁）
- 稳定集合 = 决策集（喂落地方向：甲方有未引用→铺内容；真劣势→对标竞对）。

### 4.3 L3 漂移检测
- run1 vs runN：平台命中率差 > 2×CI → 标"漂移"，不合并平均，提示"测量内容已变"。

### 4.4 停止判据（三取先到）
1. **不动点**：run r 与 r-1 的稳定集合完全相同，且模糊集为空（或已终裁）→ 停。
2. **区间达标**：所有波动平台命中率 CI 半宽 ≤ δ_hit → 停。**δ_hit 已对齐默认 = ±10pp**。
   劣势稳定 = 出现 ≥2/3（3 轮 ≥2）、模糊 = 1/3~2/3；G4 翻转率 >20% 视为协议不可信（已对齐）。
3. **硬上限** R_max=3 → 停。

### 4.5 输出（收敛报告）
- 每平台命中率均值±区间。
- 劣势维度决策集（稳定出现/稳定未现/模糊存疑）。
- 稳定性等级：`converged`（两判据满足）/ `partial`（核心稳定，个别存疑）/ `unstable`（翻转率高，协议不可信）。
- 漂移标记、缓存哨兵清单。
- **产物形态（已对齐）：落库活数据字段** `measurement_json["convergence"]`（非 sealed，像 content_assets；
  报告层/前端可读；快照仍是原始来源可续算）。

## 5. 主 agent 在环（职责边界）
- 调度 3 轮 + 30min 待采通知。
- 每轮 G1-G5 判定质量闸。
- 翻转键仲裁、存疑键终裁。
- 系统只保证确定性部分（聚合/校验/区间/分档）。

## 6. 已对齐决策（2026-09-15）

- **Q2 平台采样范围**：**分层**——波动平台（豆包/文心）命中层 3 轮、稳定平台（DS/Kimi）命中层 1 轮；归因层 4 平台每轮都采。

## 7. 重采触发规则（不按日历）

**默认不重采。** 只有"需要新基线/新数字"才跑 3 轮收敛；常规复测单次即可，靠基线已锁的 CI 对比。

| 触发事件 | 动作 | 依据 |
|---|---|---|
| 首次 / 换甲方 / 换城市 | 3 轮收敛锁基线（B 模式） | 决策节点 |
| 问法变更（题目净化 / 甲方指定问法） | 指纹变 → run_measure 自动开新基线 → 需 3 轮收敛 | 基线变更模式 |
| P2 刷新（定位超 30 天） | 重跑 P2 → 重采 | `positioned_at` 新鲜度 |
| 合同到期复测 | **单次 run** + 与基线 CI 对比（落在 CI 内 = 无显著变化；落在外 = 显著 → 决定是否重跑 3 轮刷新基线） | 合同验收机制 |
| 漂移告警（L3：跨 run 差 > 2×CI） | 人工确认是否重采 | 报告期检测 |

**为什么不需要每天重采**：收敛周期由"决策节点 + 失效信号"触发，不是日历；同基线收敛完即停（R_max 兜底）；稳定平台不重复采；到期复测用"单次 + 基线 CI 对比"成本最低。
