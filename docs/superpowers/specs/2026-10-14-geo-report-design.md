# GEO 诊断报告设计（福州香格里拉）

- 日期：2026-10-14
- 数据基线：V6（run `535b8108`，快照 1，system=B）
- 交付物：面向甲方管理层的 AI 可见度诊断报告
- 状态：设计已定稿（用户逐节确认）

## 1. 目标与受众

- **受众**：甲方管理层（决策层）。
- **目的**：让管理层先"看见"品牌在 AI 世界里的现状，认可两处短板，并感到竞对正在追赶的紧迫感，为后续合作铺垫。
- **基调**：稳中求进为主（先肯定成绩 → 聚焦短板）+ 一点竞对危机感。
- **语言**：全篇业务语言。**不出现**脚本、系统、字段、技术实现等字眼——只讲"AI 怎么看这个品牌、甲方处在什么位置、为什么、往哪走"。

## 3. 章节结构（方案 B · 问题驱动，约 32–38 页）

| 章 | 内容 | 页 |
|---|---|---|
| 封面 | 品牌 + 「AI 可见度诊断报告」+ 核心结论（命中率 78.7%）+ 评估范围（18 题 × 4 AI）+ 数据时间 | 1 |
| 执行摘要 | 一句话结论 + 3 个优势 + 2 个风险 + 优先方向 | 1–2 |
| ① 我们做得怎么样 | 整体命中率 + 4 个 AI 分平台 + 首推率/平均排名 + **口径说明** | 3 |
| ② AI 可见度主战场：四大场景 | 场景总览 + 商旅/餐饮/亲子/婚宴会议各 1 页（甲方命中率 + AI 提问样例 + 各 AI 稳/弱 + 典型 AI 原话） | 5–6 |
| ③ 威胁：竞对正在追赶 | 甲方 vs 竞对命中率对比（总 + 分平台）+ 主/次竞对定位 + 档位 + AI 共现频次 + 来源说明 | 3 |
| ④ 拖累：舆情在拉低可见度 | 负面率 + 主题分布（卫生门）+ 有效可见度折损 + 来源 | 3 |
| ⑤ 被低估的资产：AI 眼中的福州香格里拉 | AI 引用了什么 / 有但没被引用什么 + 跨平台互证 / 过时提示 | 3–4 |
| ⑥ 为什么：归因分析 | 7 维优劣势（带 AI 原话）+ 设施真劣势 + 归因主方向 | 3–4 |
| 方向（怎么改） | 针对有证据的短板给方向，不展开具体方案 | 2–3 |
| 附录 | 各 AI 逐题命中明细 + 口径与方法说明（18 题清单 + 数据来源与时间） | 6–8 |

**叙事主线**：我们做得怎么样 → 但有两处威胁（竞对追赶 / 舆情拖累）→ 其实好牌没打好（被低估的资产）→ 为什么 → 怎么办。

## 5. 口径与措辞原则

### 5.1 写进报告（甲方可见）

1. **命中率的业务化定义**：命中率 = 在 AI 给出了酒店推荐的那些回答里，AI **主动推荐**福州香格里拉的比例。（不含 AI 只答区域、没给酒店名单的回答。）
2. **来源声明**（正文 + 附录各一处）：「本次评估基于甲方指定的 **18 个高频问题 × 4 个主流 AI**（DeepSeek / Kimi / 豆包 / 文心）= 72 次提问。**换一批问题或关键词，命中率会变化——本报告结论仅对这 18 题成立**。」
3. **竞对可比性**：竞对命中率使用同一批 18 题、同一口径，可与甲方直接比较。
4. **数据时间**：2026-10-14。
5. **证据可回溯**：每个结论可翻到 AI 原话（附录逐题明细）。

### 5.2 写作规则（甲方不可见）

- 全篇业务语言，无系统 / 脚本 / 字段 / 技术实现。
- 措辞统一。

### 5.3 舆情终判（2026-10-14 补做）

V6 舆情停在 `preliminary`（终判环节漏跑），粗筛 17 条候选含误判（预售页/百科页/他城/无关主题）。
主 agent 逐条终判：**11 条真负面 / 6 条排除** → 负面率 0.1735→**0.1196**、有效可见度 0.6917→**0.7214**、
status `confirmed`；`backfill` 重盖章（同基线 V6、不新增快照版本）。
报告负面页列出**11 条真负面（含来源 URL）**，可逐条核验。

### 5.4 例外（用户决定）

- **文心平台不标注采集缺口**：文心数值（46.2%）照实呈现，但不加"有效样本不足 / 限流"之类说明。（已知影响：文心 46.2% 中有一部分由采集缺口造成，不标注时可能被读作"文心就是不推荐香格里拉"。）

## 6. 工作流

**HTML 优先**：

1. 按本设计产出 **HTML** 版报告。
2. 用户在浏览器预览、迭代确认。
3. 通过后按 HTML 转为 **PDF**（甲方要备案，最终交付 PDF）。

## 7. 非目标

- 不含具体落地方案（只给方向）。
- 不含竞对卡片（优势 / 短板 / 简介 / 官网）——该数据未采集。
- 报告结构**不复刻**参考 PDF，仅借鉴其"让甲方看见 AI 世界里的自己"的思路。
